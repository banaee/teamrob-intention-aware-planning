# Framework HRI

This repository contains the `framework_HRI` ROS 2 Humble package with its JAX, CUDA, cuDNN, and GPU environment packaged in Docker.

## Requirements

The host computer must have:

* Linux
* An NVIDIA GPU
* NVIDIA driver
* Docker Engine
* Docker Compose
* NVIDIA Container Toolkit

Verify that Docker can access the GPU:

```bash
docker run --rm --gpus all \
  nvidia/cuda:12.4.1-base-ubuntu22.04 \
  nvidia-smi
```

## Clone the repository

```bash
git clone <repository-url>
cd framework_HRI
```

For a specific branch:

```bash
git clone --branch <branch-name> <repository-url>
cd framework_HRI
```

## Build the Docker image

Run this command from the directory containing `Dockerfile` and `compose.yaml`:

```bash
docker compose build
```

## Verify JAX GPU access

```bash
docker compose run --rm framework-hri \
  python3 -c "import jax; print(jax.devices())"
```

The output should contain:

```text
[cuda(id=0)]
```

## Run the framework

```bash
docker compose run --rm framework-hri \
  ros2 launch framework_HRI framework_visualization.launch
```

If the launch file is named `framework_visualization.launch.py`, use:

```bash
docker compose run --rm framework-hri \
  ros2 launch framework_HRI framework_visualization.launch.py
```

Stop the framework with:

```text
Ctrl+C
```

## Interactive container

To open a terminal inside the container:

```bash
docker compose run --rm framework-hri bash
```

Then run:

```bash
ros2 launch framework_HRI framework_visualization.launch
```

Leave the container with:

```bash
exit
```

## Rebuild after updating the code

After pulling new changes:

```bash
git pull
docker compose build
```

Then run the launch file again.
