PLANNER 2 — kitting domain (ACTIVE — PRIEST running)
------------------------------------------------------
Layout: domains/kitting/env_layout1.json
Shows:  zones (colored floor panels), shelves, item IDs, kitting table,
        obstacles, robot (moving), human (static), coffee machine,
        PRIEST trajectory (red line), current goal (red cylinder),
        task label (current task + current action)

Task source: scenario_10 from domains/kitting/scenarios.py
             robot_0 assigned: item_5, item_1, item_7
Task planning: AdaptivePlanner from shared/planner.py
               produces AbstractPlan (4 actions: move_to → pick_up → move_to → place)
Execution: ActionExecutor (ContinuousExecutor.py)
           move_to  → resolves item/shelf position from JSON → sends goal to PRIEST
           pick_up  → waits pick_delay (2s)
           place    → waits place_delay (2s)
           completion checked via WorldState predicates (at, holding, obj_at)
Motion: PRIESTLocalPlanner — continuous collision-avoiding trajectory
        obstacles and human position read from layout (static for now)
        robot state updated by Euler integration each tick (dt=0.1s)
