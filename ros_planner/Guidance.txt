
1: I have assumed 6 different tasks, each including going to object, picking item, going to delivery desk, placing it. Here environment is static, obstacles have been defined as orange circles and human is also assumed to be static. Blue point is the initial point for robot and each red point is like the current goal of the robot for current action. this core is just a proof of concept how my local planner can react in ideal scenarion and under this setting. To run the code after checking planner_node inside lunch file which should be planner_1:
 
	ros2 launch planner planner_visualization.launch.py

3: Next step is to give the created words to Hadi to use them on MESA. Two python codes
have been written. one of them convert sdf to yaml file and the other one convert .world to both .yaml and .json files. 4: In this step we add interruption to tasks and run our code again. Interruptions include 4 cases, when going to object -> just cancel the current task, going to targer -> going back to object and place the object back, picking up or placing and item -> contiue the ask and ask human to wait for a couple of seconds. for each task, we have an id, and also we have interruptions while going to object or going to target:

	ros2 launch planner planner_visualization_interrupt.launch.py
